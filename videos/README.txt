VIDEOS FOLDER

Home page video (optional):
  hero.mp4         - landscape, plays behind the headline on computers
  hero-mobile.mp4  - portrait (optional), used on phones; if missing, hero.mp4 is used
  Keep each clip 6-12 seconds, muted, MP4, under ~6MB. If no file is here, the photo shows instead.

Piece videos (optional):
  Name them after the piece, e.g. van-cleef-arpels-sapphire-ring.mp4,
  and add  video: "videos/van-cleef-arpels-sapphire-ring.mp4"  to that piece in data/pieces.js.
